# sistema-gest-o-cemit-rio-carvalho-sagrado
1- Introdução: O seguinte repositório visa realizar uma atividade promovida pelo professor Fábio Penha, e concebe a ideia de um cemitério fictício: "Cemitério Carvalho Sagrado".
2- Objetivos: Hipoteticamente, meu banco de irá armazenar os dados dos clientes do cemitério e oferecer serviços e produtos para os mesmos.
3- Funcionalidades Oferecer um formulário de cadastramento, sistema de compra de itens funerários, agendamento de serviços, ofertas e sistema de fidelidade.
