# Sistema de Gestão - Cemitério Carvalho Sagrado 🪦

Repositório criado para a atividade prática proposta pelo professor **Fábio Penha**, com o objetivo de modelar e implementar um banco de dados para um sistema de gestão cemiterial.

---

## 📌 1. Introdução e Contexto

O **Cemitério Carvalho Sagrado** é uma instituição fictícia criada para simular os desafios operacionais e administrativos de um cemitério moderno. O sistema visa otimizar o fluxo de atendimento aos clientes, centralizando o armazenamento de dados e a oferta de serviços e produtos especializados.

---

## 🎯 2. Objetivos do Banco de Dados

O banco de dados foi projetado para armazenar, gerenciar e assegurar a integridade das informações do cemitério, permitindo:
*   Armazenar o histórico e dados cadastrais dos clientes e beneficiários.
*   Controlar o estoque e a venda de itens funerários.
*   Gerenciar o agendamento e a execução de serviços cemiteriais.
*   Operar campanhas de ofertas e controlar um sistema de fidelidade para clientes.

---

## ⚙️ 3. Regras de Negócio

1. **Gestão de Clientes:** O sistema deve manter um cadastro completo dos clientes, permitindo o vínculo com contratos de jazigos, produtos e serviços adquiridos.
2. **Produtos Funerários:** A compra de itens funerários deve registrar a transação e atualizar o controle de disponibilidade.
3. **Agendamento de Serviços:** Os serviços oferecidos devem ser agendados vinculando data, horário, cliente e o tipo de atendimento solicitado.
4. **Sistema de Fidelidade e Ofertas:** Clientes cadastrados podem participar de um programa de fidelidade, acumulando vantagens ou descontos em ofertas especiais disponibilizadas pelo cemitério.

---

## 🔄 4. Processos Principais (Tarefas Atendidas)

*   **Cadastramento:** Formulário unificado para registro e atualização de dados de novos clientes.
*   **Loja de Produtos:** Sistema de compra de itens funerários.
*   **Agendamento de Serviços:** Módulo para marcação e controle de serviços prestados.
*   **Fidelidade e Promoções:** Gestão de ofertas e pontuação/vantagens do sistema de fidelidade.
