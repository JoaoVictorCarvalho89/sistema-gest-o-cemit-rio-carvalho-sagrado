# sistema-gest-o-cemit-rio-carvalho-sagrado
O seguinte repositório visa realizar uma atividade promovida pelo professor Fábio Penha, e concebe a ideia de um cemitério fictício: "Cemitério Carvalho Sagrado".
Hipoteticamente, meu banco de irá armazenar os dados dos clientes do cemitério e oferecer serviços e produtos para os mesmos.
